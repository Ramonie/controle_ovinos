# 🐑 AuctionEAJ – Sistema Web de Gerenciamento de Leilões de Animais

O **AuctionEAJ** é um sistema web desenvolvido com Python e Django, destinado ao gerenciamento e à realização de leilões de animais da Escola Agrícola de Jundiaí (EAJ/UFRN).

A plataforma tem como finalidade informatizar e facilitar os processos envolvidos na organização de leilões, permitindo o cadastro de animais, a formação de lotes, a divulgação dos leilões e o acompanhamento dos lances. O sistema busca centralizar as informações, proporcionar maior organização e oferecer uma experiência mais eficiente aos administradores e participantes.

## 🚀 Funcionalidades Principais

### 🐑 Gerenciamento de Animais
- Cadastro de animais com informações detalhadas;
- Identificação individual por número de brinco;
- Registro de raça, sexo e cor;
- Cadastro de peso, altura e data de nascimento;
- Informações reprodutivas;
- Registro da filiação (pai e mãe);
- Upload de fotografias;
- Consulta, edição e gerenciamento dos animais cadastrados.

### 📦 Gerenciamento de Lotes
- Criação de lotes para os leilões;
- Associação de um ou mais animais a cada lote;
- Cadastro de descrição e identificação dos lotes;
- Definição de informações comerciais;
- Visualização dos animais que compõem cada lote.

### 🔨 Gerenciamento de Leilões
- Cadastro e organização de leilões;
- Disponibilização dos lotes para participação;
- Consulta aos leilões disponíveis;
- Visualização dos detalhes dos lotes;
- Acompanhamento dos lances;
- Registro dos resultados e arremates.

### 🔐 Gerenciamento de Usuários
- Autenticação de usuários;
- Login e logout;
- Controle de acesso conforme as permissões;
- Funcionalidades administrativas restritas a usuários autorizados.

### 📱 Interface do Sistema
- Interface responsiva;
- Utilização do Bootstrap 5;
- Navegação intuitiva;
- Exibição dos animais e lotes em cards;
- Páginas individuais para consulta dos detalhes.

## 🛠️ Tecnologias Utilizadas

## 🎯 Objetivo do Projeto

Desenvolver uma plataforma web para modernizar e otimizar o gerenciamento de leilões de animais da Escola Agrícola de Jundiaí, centralizando o cadastro dos animais, a formação de lotes e o acompanhamento das negociações em um ambiente digital.
